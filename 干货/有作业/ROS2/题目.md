# 11 课后作业：矩形与三角形巡逻节点

## 题目原文

参考正方形程序，独立编写 rectangle_patrol.py，使海龟从重置位置完成一圈三角形运动。

只需要提交 python 文件和小海龟仿真运行效果图。

## 修正后的实现要求

- 截图标题为“矩形巡逻节点”，正文要求“一圈三角形运动”。现明确修正为：矩形与三角形两种轨迹都要实现。
- 参考正方形程序，分别编写 `rectangle_patrol.py` 和 `triangle_patrol.py`。
- 矩形巡逻：使海龟从重置位置出发，完成一圈矩形运动。
- 三角形巡逻：使海龟从重置位置出发，完成一圈三角形运动。
- 两种轨迹分别运行，每次均从重置位置开始，完成后停止。
- 提交材料：两个 Python 程序文件，以及矩形、三角形各自的小海龟仿真运行效果图。

## 节点实现与运行

- `rectangle_patrol.py`：节点名 `rectangle_patrol`，完成宽 3、高 2 的矩形轨迹。
- `triangle_patrol.py`：节点名 `triangle_patrol`，完成边长 3 的等边三角形轨迹。
- 两个程序均可独立运行，不依赖额外的自定义 Python 模块。
- 每次运行先调用 `/reset`，订阅 `/turtle1/pose`，通过 `/turtle1/cmd_vel` 控制运动；使用位姿反馈依次转向和走边，完成后恢复初始朝向、发送零速度并退出。
- 顶点位置允许误差为 0.025，最终朝向允许误差为 0.015 弧度。按作业要求精简实现，保留等待服务、重置响应和首帧位姿的正常流程，不设置超时或反馈中断检查。

先在一个终端启动仿真：

```bash
source /opt/ros/humble/setup.bash
ros2 run turtlesim turtlesim_node
```

在本目录的另一个终端运行矩形节点：

```bash
source /opt/ros/humble/setup.bash
python3 rectangle_patrol.py
```

保存矩形运行效果图后，再运行三角形节点：

```bash
python3 triangle_patrol.py
```

请依次运行两个节点。每次运行会重置仿真并清除上一次轨迹；运行期间不要同时使用键盘遥控或其他速度控制节点。
